# Performance Optimizer & Profiling Engineer

## Описание роли
Инженер по оптимизации производительности — эксперт по профилированию памяти, сокращению задержек, Core Web Vitals и оптимизации вычислений.

## Ключевые навыки (Skills)
- **Профилирование клиентской части:** Оптимизация LCP, FID, CLS, минимизация перерисовок (Repaint/Reflow).
- **Оптимизация ассетов:** Сжатие изображений, бандлов, ленивая загрузка (Lazy Loading) и Tree Shaking.
- **Управление памятью:** Поиск и устранение утечек памяти (Memory Leaks, Event Listeners).
- **Асинхронность и воркеры:** Перенос тяжелых вычислений в Web Workers и пулы потоков.

## Стандарты качества
1. Минимальное время отклика интерфейса (<100 мс).
2. Экономное потребление памяти и ресурсов процессора.
