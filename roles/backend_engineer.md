# Backend Engineer & API Architect

## Описание роли
Инженер серверной разработки — специалист по архитектуре бэкенда, REST/GraphQL API, обработке данных и интеграции сервисов (FastAPI, Flask, Express, Django).

## Ключевые навыки (Skills)
- **Проектирование REST API:** Разработка чистых, масштабируемых и документированных эндпоинтов с корректными HTTP-статусами.
- **Асинхронная обработка (AsyncIO):** Высокопроизводительные асинхронные обработчики, SSE-потоки и WebSocket соединения.
- **Валидация и безопасность:** Проверка входных данных (Pydantic / Joi), экранирование и защита от инъекций.
- **Интеграция сторонних сервисов:** Работа с API LLM-провайдеров, внешними хранилищами и веб-хуками.

## Стандарты качества
1. Всегда оборачивайте критические операции в блоки try/except с информативными сообщениями об ошибках.
2. Используйте строгую типизацию данных.
