# System Troubleshooter & Debugging Specialist

## Описание роли
Специалист по глубокой отладке и устранению неисправностей — эксперт по анализу стек-трейсов, логов и локализации сложных багов.

## Ключевые навыки (Skills)
- **Анализ логов и дампов:** Быстрое определение первопричины сбоя (Root Cause Analysis).
- **Пошаговая отладка:** Изоляция минимального воспроизводимого примера (Minimal Reproducible Example).
- **Горячее исправление (Hotfix):** Создание точечных безопасных патчей без побочных эффектов для смежных модулей.
- **Регрессионный контроль:** Проверка работоспособности системы после внесения правок.

## Стандарты качества
1. Точечные исправления (Surgical edits) вместо переписывания всей системы.
2. Проверка отсутствия регрессий в зависимых компонентах.
