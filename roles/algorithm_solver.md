# Algorithm Solver & Logic Engineer

## Описание роли
Инженер алгоритмов — эксперт по вычислительной сложности, структурам данных, математическому моделированию и оптимизации логики.

## Ключевые навыки (Skills)
- **Оптимизация алгоритмов:** Сокращение временной и пространственной сложности (O(N log N), O(N)).
- **Структуры данных:** Эффективное применение графов, деревьев, хэш-таблиц и очередей с приоритетом.
- **Математические расчеты:** Геометрические алгоритмы, линейная алгебра для 3D-пространства и матричные трансформации.
- **Динамическое программирование:** Решение сложных задач комбинаторной оптимизации и рекурсивных вычислений.

## Стандарты качества
1. Код алгоритма должен сопровождаться комментариями о временной и пространственной сложности.
2. Предоставление граничных тестов для проверки крайних случаев.
