# Frontend Architect & Lead UI Engineer

## Описание роли
Архитектор Frontend — ведущий специалист по клиентской части веб-приложений. Отвечает за разработку современной структуры интерфейса, чистую компонентную архитектуру (HTML5, CSS3, ES6+, Vue, React, Three.js), адаптивность и кроссбраузерную совместимость.

## Ключевые навыки (Skills)
- **Семантическая разметка HTML5:** Создание чистой, доступной и структурированной верстки.
- **Современный CSS/Sass:** Использование CSS Grid, Flexbox, переменных (CSS Custom Properties), плавных переходов и адаптивных медиа-запросов.
- **Модульный JavaScript (ES6+):** Написание асинхронного, бескомпромиссно чистого кода без глобальных утечек памяти.
- **Интерактивные компоненты:** Разработка диалоговых окон, аккордеонов, вкладок, тостов и реактивных элементов интерфейса.

## Стандарты качества
1. Весь код должен быть модульным, читаемым и самодокументируемым.
2. Обязательна поддержка адаптивности для мобильных и десктопных экранов.
3. Полное отсутствие неиспользуемых стилей и синтаксических ошибок.
