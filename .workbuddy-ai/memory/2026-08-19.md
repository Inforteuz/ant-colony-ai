## Stop tugmasi ishlamas muammosi — tubdan tuzatildi

Foydalanuvchi PM Console screenshot yubordi: PM "Размышление (Thinking)..."
bosqichida qotib qolgan, stop buyrug'i bergan, lekin ish davom etayapti.
Chuqur tekshiruv — bu yerda bir nechta bog'liq bug bor edi:

1. **`checkAndReconnectActiveJob` da `isRunning=true` o'rnatilmagan** — sahifa
   reload yoki PM Console kech ochilganda serverda vazifa running bo'lsa ham
   frontend `isRunning=false` qolardi → "Стоп" tugmasi `.btn-pm-stop.hidden`
   klassi bilan yashirin edi. Foydalanuvchi faqat chat inputiga "стоп" deb
   yozardi, bu esa yangi vazifa yaratardi.
2. **`run()` `except CancelledError` final event chiqarmagan** — cancel
   qilinganda `orchestration_cancelled` frontend'ga yetkazilmasdi. Shuning
   uchun "В эфире" yozuvi va spinner abadiy qolardi.
3. **SSE generator timeout-cancelled holatda darrov `break` qilardi** — final
   event navbatda bo'lsa ham yetkazilmasdi.
4. **Chat inputida stop kalit so'zlari interceptor'siz** — "стоп", "stop",
   "to'xtat", "cancel", "прекрати", "отменить" so'zlari dispatchga borardi.
5. **`stopPMTask` UI ni zudlik bilan yangilamasdi** — server javobini kutardi.

### Tuzatishlar

**Backend (`ant_colony/server.py`):**
- `/api/orchestrator/cancel`: `CURRENT_JOB` None/finished bo'lsa ham
  `ACTIVE_JOBS` ichidan eng so'nggi running job'ni topadi, `CURRENT_JOB` ni
  sinxronlaydi. Cancel'dan oldin `orchestration_cancelled` event o'zi emit
  qiladi. Javobga `job_id` qo'shildi.
- SSE generator: timeout-cancelled holatda 200ms ichida queue'dan final event
  olishga urinib, keyin `break`. Bu event kafolatli yetkaziladi.
- `OrchestrationJob.run()` `except asyncio.CancelledError`: shu yerda ham
  `orchestration_cancelled` emit qiladi (defense-in-depth).

**Frontend (`static/js/app.js`):**
- `checkAndReconnectActiveJob`: status==='running' da `setPMRunning(true)` +
  liveWorkspace "В эфире". status==='cancelled' da `setPMRunning(false)` +
  "Остановлено".
- `stopPMTask`: server javobidan oldin UI ni zudlik yangilaydi
  (finalizeThinkingCards, "Остановлено пользователем", dots o'chirish,
  liveWorkspace "Остановлено"), keyin `fetch('/api/orchestrator/cancel')`.
- `handleOrchestratorEvent`: yangi `orchestration_cancelled` handleri —
  setPMRunning(false), liveWorkspace stopped, thinking collapsed+finalizatsiya,
  toast "Оркестрация отменена".
- `dispatchPMTask` stop-keyword interceptor (regex): `стоп|stop|to'?xtat
  (?:ish)?|toxta|cancel|прекрати(?:ть)?|отмени(?:ть)?|прерв(и|ите)|ишни\s+to'?xtat`.
  Faqat shu kalit so'z + `isRunning===true` bo'lsa, `stopPMTask()` chaqiriladi.

**Cache-bust:** `app.js`/`hive3d.js` `?t=1787084500` → `1787135651`.
