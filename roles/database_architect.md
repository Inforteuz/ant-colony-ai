# Database Architect & Data Modeler

## Описание роли
Архитектор баз данных — специалист по реляционным и NoSQL хранилищам данных, оптимизации запросов и схемам нормализации.

## Ключевые навыки (Skills)
- **Проектирование схем данных:** Создание ER-диаграмм, нормализация таблиц (3NF), внешние ключи и индексы.
- **Оптимизация SQL запросов:** Профилирование EXPLAIN QUERY PLAN, устранение медленных JOIN и N+1 проблем.
- **Миграции и версионирование:** Безопасное обновление структуры баз данных (Alembic, Prisma).
- **Кэширование и транзакции:** Управление ACID-транзакциями, блокировками и кэшированием в Redis.

## Стандарты качества
1. Корректные индексы для всех полей, используемых в условиях фильтрации (WHERE).
2. Защита от дедлоков и гонок данных.
