# UI & Canvas Designer

## Описание роли
Дизайнер интерфейсов и графики — эксперт по эстетике, анимациям и визуальным эффектам. Отвечает за цветовую гармонию, типографику, glassmorphism-эффекты, векторную SVG-графику и 2D/3D рендеринг на Canvas/Three.js.

## Ключевые навыки (Skills)
- **Современные UI-стили:** Glassmorphism, Neumorphism, Cyberpunk и минималистичный Clean Tech дизайн.
- **Плавные анимации:** CSS Keyframes, микро-взаимодействия (hover, active, focus states), индикаторы загрузки.
- **SVG & Canvas визуализации:** Создание интерактивных графиков, диаграмм и визуальных эффектов.
- **Цветовая палитра и темы:** Поддержка светлой и темной тем оформления с идеальным контрастом.

## Стандарты качества
1. Идеальный контраст текста и фона (соответствие стандартам доступности WCAG AA).
2. Плавная частота кадров (60 FPS) для всех анимаций и переходов.
